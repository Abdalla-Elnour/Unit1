I. Introduction to Computer Architecture
مقدمة في هندسة الحاسب
Computer Architecture is the blueprint for how a system's hardware components are organized and interact.
هندسة الحاسب هي المخطط الأساسي لكيفية تنظيم مكونات أجهزة النظام وتفاعلها.
It acts as a bridge between software and physical hardware devices.
تعمل بمثابة جسر يربط بين البرمجيات وأجهزة المكونات المادية.

THE THREE MAIN ASPECTS:

الجوانب الثلاثة الرئيسية لهندسة الحاسب:

01 — Instruction Set Architecture (ISA)
Instruction Set Architecture (ISA) defines the interface between hardware and software, including machine instructions, data types, and registers. It determines what operations the processor can perform.
هندسة طقم التعليمات (ISA): تحدد الواجهة بين الأجهزة والبرامج، بما في ذلك تعليمات الآلة، أنواع البيانات، والسجلات. وهي التي تحدد العمليات التي يمكن للمعالج القيام بها.
02 — Microarchitecture
Microarchitecture describes how the CPU executes instructions using components such as the ALU, Control Unit, pipelines, and caches. It refers to the internal implementation of the processor.
البنية الدقيقة: تصف كيف يقوم المعالج بتنفيذ التعليمات باستخدام مكونات مثل وحدة الحساب والمنطق، وحدة التحكم، الأنابيب، والذاكرة المخبئية.
03 — System Design
System Design involves the overall structure of the computer system, including memory hierarchy, I/O systems, buses, and integration of hardware components.
تصميم النظام: يتضمن الهيكل العام لنظام الحاسوب، بما في ذلك هرمية الذاكرة، أنظمة الإدخال والإخراج، الناقلات، وتكامل مكونات الأجهزة.
⚙️
II. CPU Components and Functions
مكونات ووظائف المعالج
The CPU is the core of the system where all logical and arithmetic processing occurs.
وحدة المعالجة المركزية (CPU) هي قلب النظام حيث تحدث جميع عمليات المعالجة المنطقية والحسابية.
ALU — Arithmetic Logic Unit
Arithmetic Logic Unit (ALU) performs operations like addition, subtraction, and logical comparisons.
وحدة الحساب والمنطق (ALU): تنفذ العمليات مثل الجمع، الطرح، والمقارنات المنطقية.
CU — Control Unit
Control Unit (CU) acts as the orchestrator, interpreting instructions and coordinating all system activities.
وحدة التحكم (CU): تعمل كمنظم، حيث تفسر التعليمات وتنسق جميع أنشطة النظام.
Registers
Registers are high-speed storage locations within the CPU used to hold data and instructions temporarily.
السجلات: مواقع تخزين فائقة السرعة داخل المعالج تستخدم لحفظ البيانات والتعليمات مؤقتاً.
🔌
III. The System Bus
ناقل النظام
The System Bus is the information highway that interconnects all components for data exchange.
ناقل النظام هو الطريق السريع للمعلومات الذي يربط جميع المكونات ببعضها لتبادل البيانات.
Data Bus — ناقل البيانات
Data Bus transfers the actual data between the CPU and memory.
ناقل البيانات: ينقل البيانات الفعلية بين المعالج والذاكرة.
Address Bus — ناقل العناوين
Address Bus carries memory addresses to identify specific storage locations.
ناقل العناوين: يحمل عناوين الذاكرة لتحديد مواقع تخزين معينة.
Control Bus — ناقل التحكم
Control Bus transmits signals to manage timing and coordinate system operations.
ناقل التحكم: يرسل الإشارات لإدارة التوقيت وتنسيق عمليات النظام.

IV. Instruction Cycle & Architectures
دورة التعليمات والأنظمة

THE INSTRUCTION CYCLE (FETCH-EXECUTE):

دورة التعليمات (جلب - تنفيذ):

Phase 1 — Fetch / الجلب
Fetch Phase: The Control Unit retrieves the next instruction from memory using the Program Counter.
مرحلة الجلب: تستعيد وحدة التحكم التعليمية التالية من الذاكرة باستخدام عداد البرنامج.
Phase 2 — Decode / فك التشفير
Decode Phase: The fetched instruction is interpreted to determine what operation to perform.
مرحلة فك التشفير: يتم تفسير التعليمية المجلوبة لتحديد العملية المطلوب تنفيذها.
Phase 3 — Execute / التنفيذ
Execute Phase: The instruction is performed by the appropriate unit like the ALU.
مرحلة التنفيذ: يتم تنفيذ التعليمية بواسطة الوحدة المناسبة مثل وحدة الحساب والمنطق.
Phase 4 — Store / التخزين
Store Phase: The final result is saved back into memory or registers.
مرحلة التخزين: يتم حفظ النتيجة النهائية مرة أخرى في الذاكرة أو السجلات.

VON NEUMANN VS. HARVARD:

بنية فون نيومان مقابل بنية هارفارد:

Von Neumann uses unified memory for data and instructions, while Harvard uses dual separate memories.
يستخدم فون نيومان ذاكرة موحدة للبيانات والتعليمات، بينما يستخدم هارفارد ذاكرتين منفصلتين.
Harvard is faster due to parallel processing, but Von Neumann is simpler for general use.
هارفارد أسرع بسبب المعالجة المتوازية، لكن فون نيومان أبسط للاستخدام العام.

V. Computer Generations
أجيال الحاسوب
1940–1956 — First Generation
First Generation relied on Vacuum Tubes, which were bulky and inefficient.
الجيل الأول: اعتمد على الأنابيب المفرغة، التي كانت ضخمة وغير فعالة.
1956–1963 — Second Generation
Second Generation introduced Transistors, which were smaller, faster, and more reliable.
الجيل الثاني: قدم الترانزستورات، التي كانت أصغر وأسرع وأكثر موثوقية.
1964–1971 — Third Generation
Third Generation used Integrated Circuits (ICs) to combine multiple transistors on one chip.
الجيل الثالث: استخدم الدوائر المتكاملة لدمج ترانزستورات متعددة على شريحة واحدة.
1971–Present — Fourth Generation
Fourth Generation developed Microprocessors using VLSI technology.
الجيل الرابع: طور المعالجات الدقيقة باستخدام تقنية VLSI.
Future — Fifth Generation
Fifth Generation focuses on Artificial Intelligence (AI) and parallel processing.
الجيل الخامس: يركز على الذكاء الاصطناعي والمعالجة المتوازية.
